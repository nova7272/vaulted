> Maintained as a compact project map for AI agents and developers. Update this file when the repository structure changes significantly.

## Project Overview
Vaulted is an encrypted file vault with local Vaulted seed identity, client-side encryption, local XRPL signing, Oracle coordination, and encrypted fragment storage. See `.ai-factory/DESCRIPTION.md` for the full project context.

## Tech Stack
- **Programming language:** Rust 2021 workspace
- **Desktop framework:** Tauri 2
- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS
- **Backend:** Axum, Tokio
- **Database:** PostgreSQL via `sqlx`
- **Cache:** Redis
- **Infrastructure:** Docker Compose

## Project Structure
```text
.
+-- crates/
|   +-- crypto-core/        # Shared cryptography, identity, envelopes, manifests, QR payloads, XRPL wallet helpers
|   +-- desktop-client/     # Tauri desktop app, local secret handling, secure storage, file workflows
|   |   +-- ui/             # React/Vite frontend
|   +-- oracle/             # Axum registry/auth/manifest/grant/device/XRPL verification service
|   +-- storage-node/       # Encrypted fragment storage service
+-- migrations/             # PostgreSQL schema and compatibility migrations
+-- scripts/                # Security and developer helper scripts
+-- data/                   # Local development fragment data
+-- .codex/                 # Local AI Factory skills, agents, and config
+-- .ai-factory/            # Project AI context generated by AI Factory
+-- docker-compose.yml      # Local PostgreSQL, Redis, and dev tools
+-- Makefile                # Common development commands
+-- Cargo.toml              # Rust workspace manifest
+-- README.md               # Human-facing project overview and quick start
```

## Agent Rules
- Decompose shell commands instead of chaining unrelated operations.
  - Incorrect combined command: `git checkout main && git pull`
  - Correct sequence: first `git checkout main`, then `git pull origin main`
- Do not fetch external skills or dependencies unless the user explicitly confirms that network/DNS access should be used.
- Respect the trust boundary: plaintext file content, file keys, seed phrases, and private wallet material stay client-side.
- Use existing workspace commands and scripts before inventing new workflows.
- Before planning or implementing product work, read `.ai-factory/VAULTED_AGENT_INSTRUCTIONS.md` together with `.ai-factory/DESCRIPTION.md`, `.ai-factory/ARCHITECTURE.md`, and `.ai-factory/rules/base.md`.
- Follow the immediate task order from `.ai-factory/VAULTED_AGENT_INSTRUCTIONS.md` unless the user explicitly overrides it.
