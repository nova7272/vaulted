## Current expected auth behavior

- Seed is not persisted.
- Identity/wallet/session are memory-only.
- Restart returns app to locked/Auth UI.
- Unlock after restart requires restoring with the 12-word phrase.
- Sign out locks memory session; it is not destructive reset.
- Create wallet generates exactly 12 words.
- Restore accepts exactly 12 words.
- 24-word seed generation/restore is not supported in the production MVP policy.

## Security boundaries

Do not log or expose:

- seed phrase
- mnemonic entropy
- private keys
- derived keys
- AES keys
- JWT / refresh tokens
- plaintext files
- decrypted content
- `tx_blob`
- signatures
- raw restore input
